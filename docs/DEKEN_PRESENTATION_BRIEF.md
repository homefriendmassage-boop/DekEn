# DekEn — เอกสารสรุปโปรเจกต์สำหรับทำ Storyboard / วิดีโอพรีเซนต์

> เอกสารนี้สรุปทุกอย่างที่ระบบทำได้ ณ ปัจจุบัน เขียนให้คน (หรือ Claude) ที่ไม่เคยเห็นโปรเจกต์นี้ นำไปวางโครงเรื่อง ทำ Storyboard และสร้างวิดีโอพรีเซนต์ได้
> ข้อมูลทั้งหมดมาจากโค้ดใน repo นี้ (`README.md` มีรายละเอียดเทคนิครายไมเกรชัน) ตัวเลขราคา/กติกาอยู่ในหัวข้อ 6
> **หมายเหตุความจริง:** ฟีเจอร์ถูกทดสอบด้วยฐานข้อมูลจำลองและเบราว์เซอร์จำลอง ยังไม่ได้ยืนยันครบกับ LINE และข้อมูลจริง ห้ามพูดในวิดีโอว่า "ผ่านการใช้งานจริงแล้ว" ถ้าผู้ใช้ยังไม่ยืนยัน

## 1. โปรเจกต์คืออะไร (ประโยคเดียว)
**DekEn** คือแพลตฟอร์มบน LINE (LIFF) ที่ให้ลูกค้าค้นหา แชต และจองผู้ให้บริการอิสระ (ชงเหล้า, ENT, หมอนวด, สปา) โดยมีระบบกระเป๋าเงิน, แพ็กเกจสมาชิก, โมเดลลิ่ง/สังกัด, ตัวแทนขาย (เซลล์), การถอนเงินพร้อมใบหัก ณ ที่จ่าย และหลังบ้านแอดมินครบวงจร

## 2. ผู้ใช้ 6 กลุ่ม (ตัวละครในวิดีโอ)
| ตัวละคร | เป้าหมาย | ใช้ทำอะไร |
|---|---|---|
| **ลูกค้า** | หาน้อง/จอง | ดูรายชื่อ, แชต, จอง, เติม Wallet, ซื้อแพ็กเกจ |
| **ผู้ให้บริการ (น้อง)** | รับงาน | สมัคร, ตั้งราคา, เปิด/ปิดออนไลน์, รับจอง, ตอบแชต, ถอนรายได้ |
| **โมเดลลิ่ง/สังกัด** | ดูแลน้องหลายคน | สร้างแบบร่างใบสมัครให้น้อง, หน้าสังกัด, แชตแทนน้อง |
| **เซลล์ (ตัวแทนขาย)** | หารายได้จากการชวน | ลิงก์ชวนลูกค้า รับส่วนแบ่ง 40% ค่าจอง + 20% ค่าแพ็กเกจ |
| **ร้าน/ผู้ขายมี LINE OA ของตัวเอง (Vendor)** | ให้ลูกค้าตัวเองเข้าระบบ | LIFF/OA ของตัวเอง, ทีมงานตอบแชตลูกค้า |
| **แอดมิน** | ดูแลแพลตฟอร์ม | อนุมัติ, ตรวจสลิป, จัดการแชต, ถอนเงิน, รายงาน |

## 3. สถาปัตยกรรม (สำหรับฉากอธิบายเทคนิค)
- ฝั่งหน้าเว็บ: Vite + React + Tailwind โฮสต์บน GitHub Pages เปิดผ่าน **LINE LIFF** (ล็อกอินด้วยบัญชี LINE ไม่ต้องสมัครสมาชิกใหม่)
- ฝั่งหลังบ้าน: **Supabase** (Postgres + Row Level Security, Edge Functions, Storage, Vault, pg_cron)
- การเงิน/สิทธิ์ทั้งหมดตัดสินที่ฐานข้อมูล (ฟังก์ชัน SECURITY DEFINER) ไม่เชื่อค่าจากหน้าเว็บ
- แจ้งเตือนผ่าน **LINE Flex Message** (ผ่าน Edge Function `notify-chat`)
- ตรวจสลิปโอนเงินอัตโนมัติ (Edge Function `verify-slip`)
- ความปลอดภัย: ข้อมูลสำคัญ (เลขบัตร, ที่อยู่, พร้อมเพย์) เข้ารหัสด้วยกุญแจใน Vault, ฟังก์ชันแอดมินตรวจสิทธิ์ทุกครั้ง, ไม่เก็บ secret ในโค้ดหน้าเว็บ

## 4. ฟีเจอร์แยกตามตัวละคร (ใช้เป็นฉากในวิดีโอ)

### 4.1 ลูกค้า
1. **เปิดผ่าน LINE** (`https://liff.line.me/<LIFF_ID>?open=home`) ล็อกอินอัตโนมัติ ยอมรับข้อตกลง (อายุ 20+, ห้ามแลกเปลี่ยนข้อมูลติดต่อ, แชตอาจถูกตรวจเมื่อมีการร้องเรียน)
2. **เลือกหมวด**: ชงเหล้า, ENT (ดูฟรี), หมอนวด (Platinum ขึ้นไป), สปา (Diamond)
3. **หน้ารายชื่อน้อง**: การ์ดน้องพร้อมสถานะออนไลน์/ไม่ว่าง, ราคาเริ่มต้น, ป้ายยืนยันพิกัด, ตัวกรองจังหวัด, ปุ่ม "ใกล้ฉัน ≤ 50 กม.", ลำดับสุ่มหมุนเวียนรายวันเพื่อความเป็นธรรม
4. **สิทธิ์ดูรูป**: ไม่มีแพ็กเกจ = เห็นรูปปิดหน้า (โมเสก) ยกเว้นบางส่วนที่เห็นหน้าชัด (ชงเหล้า/ENT 6 คน, หมอนวด 3 คน, สปา 0) แพ็กเกจที่สูงขึ้นปลดล็อกหมวดและหน้าชัด
5. **แถบสังกัด** (migration_058) แถบโลโก้โมเดลลิ่งด้านบนรายชื่อ กดเข้า **หน้าสังกัด** เห็นน้องของสังกัดนั้น แชร์ลิงก์/QR/Flex ได้
6. **แชตกับน้อง**: เปิดได้ทุกคน (ไม่ต้องมีแพ็กเกจ) ข้อความแรกกัน 40 บาทจาก Wallet (หลังกดยินยอม) คืนอัตโนมัติถ้าน้องไม่ตอบใน 3 ชม. ถ้าน้องตอบ 30 บาทเข้าบัญชีน้อง กฎแชต: ห้ามลิงก์ทุกชนิด ห้ามตัวเลข ≥2 หลัก ผิดซ้ำมีธงเตือนสีเหลือง/ส้ม/แดง และระงับห้อง
7. **แจ้งเตือนเมื่อน้องตอบ**: แถบแดงบนหน้าแอป ป้ายแดง "น้องตอบแล้ว" ที่รูปน้อง ตัวเลขที่ไอคอนแชต หายเมื่อกดอ่าน
8. **จอง**: เลือกเวลา, เลือกเส้นทาง (น้องไปหา / ลูกค้าไปหา สำหรับหมอนวด/สปา), หักค่าธรรมเนียมจอง 500 บาท (700 สำหรับหมอนวด/สปา) จาก Wallet, เห็นช่วงเวลาที่น้องไม่ว่าง
9. **เติม Wallet / ซื้อแพ็กเกจ**: QR พร้อมเพย์ ยอดไม่ซ้ำ ตรวจสลิปอัตโนมัติ ถ้าเงินใน Wallet พอ มีปุ่ม "จ่ายด้วย Wallet" เป็นปุ่มแรก
10. **รายงาน**: ปุ่มรายงานโปรไฟล์/ห้องแชต

### 4.2 ผู้ให้บริการ
1. **สมัคร**: เลือกประเภทงาน (ชงเหล้า/ENT หรือ หมอนวด/สปา), กรอกโปรไฟล์ ราคา พื้นที่ แนบรูปได้ถึง 8 รูป (ระบบทำโมเสกหน้าให้), ยืนยันอายุ (บัตร/เซลฟี่) แล้วรอแอดมินอนุมัติ (แก้ไขได้ก่อนอนุมัติ)
2. **เมื่ออนุมัติ**: ได้ Flex แจ้ง และเปิดสถานะออนไลน์อัตโนมัติ
3. **หน้าผู้ให้บริการ**: เปิด/ปิดออนไลน์, รับ-ปฏิเสธงานจอง, ตอบแชต, ดูรายได้, ขอแก้ไขโปรไฟล์ (ผ่านแอดมิน), ขอลบโปรไฟล์
4. **ระบบไม่ว่างอัตโนมัติ** เมื่อมีงานรับแล้ว (ก่อนเวลานัดและจนกดจบงาน)
5. **ถอนรายได้** ดูข้อ 4.6
6. **ระบบเช็กว่ายังทำงานอยู่** (migration_057): เงียบ 30 วันส่ง Flex ขอยืนยัน, 45 วันเตือนสุดท้าย, 60 วันซ่อนจากหน้าลูกค้าและปิดแชต/จอง, 90 วันลบโปรไฟล์ กลับมาเปิดแอปเมื่อไรก็นับใหม่และกลับมาแสดงทันที (สวิตช์ยกเลิกยอดเงินเมื่อลบ เป็น "ปิดไว้" ตามค่าเริ่มต้น)

### 4.3 โมเดลลิ่ง/สังกัด
1. สมัครด้วยชื่อ+โลโก้ รอแอดมินอนุมัติ
2. **ชำระแพ็กเกจจาก Wallet**: 1,000 บาท/30 วัน รวมน้อง 10 คน เกินคนละ 200 บาท/30 วัน
3. **เชิญน้อง**: ลิงก์/QR/Flex ที่เปิดแล้วเห็นเฉพาะหน้าสมัคร (`?agency=<code>&only=apply`) น้องเข้าสังกัดอัตโนมัติ
4. **แบบร่างใบสมัคร**: กรอกให้น้อง → ส่งแอดมินตรวจ → ได้ลิงก์ 3 วันให้น้องกดยืนยันพิกัด ซ่อน/กู้คืน/ลบถาวรได้ (ซ่อนไม่นับโควตา 40 ใบ)
5. **หน้าลูกค้า**: ป้ายสังกัด, แถบสังกัด, หน้าสังกัด, ข้อความแนะนำ (ผ่านแอดมิน) สวิตช์ แสดง/ซ่อนป้าย และแสดง/ซ่อนจำนวนน้อง
6. **ตั้งค่า**: แก้ชื่อ โลโก้ ข้อความแนะนำ → ส่งให้แอดมินอนุมัติ
7. ตอบแชตแทนน้อง, ดูน้องในสังกัด, นำน้องออกจากสังกัด
8. แพ็กเกจหมดอายุ = น้องและหน้าสังกัดไม่แสดงต่อลูกค้า (มี Flex เตือนก่อนหมด 3 วัน)

### 4.4 เซลล์ / ตัวแทน
- ซื้อแพ็กเกจเซลล์ 500 บาท/30 วัน จาก Wallet (ไม่ต้องรออนุมัติ)
- ได้ลิงก์/QR/Flex ชวนลูกค้า ลูกค้าที่จองผ่านลิงก์ → เซลล์ได้ 40% ค่าจอง (ถ้ายังเป็นเซลล์ ณ วันจอง) และ 20% ของค่าแพ็กเกจที่ลูกค้าซื้อ (ผู้ชวนคนแรกตลอดไป)
- มีหน้า "ส่วนแบ่งของฉัน" เห็นยอดและประวัติ
- แพ็กเกจหมด: ลูกค้ายังจองได้ปกติ แต่ส่วนแบ่งตกเป็นของแพลตฟอร์ม (มี Flex เตือน)
- ผู้ให้บริการเป็นเซลล์อัตโนมัติ ไม่เสียค่าแพ็กเกจเซลล์

### 4.5 Vendor (ร้านที่มี LINE OA ของตัวเอง)
- มี LIFF/OA ของตัวเอง ลูกค้ากลุ่มนั้นอยู่ภายใต้ร้าน มีทีมงานตอบแชตช่วยเหลือลูกค้า มีกล่องข้อความ (Vendor Inbox) และปุ่มล้างแชตสำหรับแอดมิน
- ข้อควรระวัง: ทุก OA ต้องอยู่ใน Provider เดียวกัน ผู้ใช้จึงเป็นบัญชีเดียว/Wallet เดียว

### 4.6 การเงินและการถอน (ขั้นที่ 6)
- กระเป๋า 2 ใบ: **Wallet** (เงินเติม ใช้จ่ายในระบบ) และ **โบนัส** (รายได้ ถอนเป็นเงินสดได้)
- ยืนยันตัวตนครั้งแรก: ชื่อตามบัตร, เลขบัตร 13 หลัก (ตรวจเลขให้), ที่อยู่, พร้อมเพย์ → แอดมินตรวจแล้วอนุมัติ (ข้อมูลเข้ารหัส)
- ขอถอน: ขั้นต่ำ 200 บาท, ค่าธรรมเนียม 20 บาทต่อครั้ง, ภาษีหัก ณ ที่จ่าย 3% (ตั้งค่าได้, ต้องให้นักบัญชียืนยัน), ถอนได้วันละ 1 ครั้ง ยอดถูกกันทันที
- แอดมินเห็นคิวถอน พร้อม **QR พร้อมเพย์ยอดสุทธิ** โอนแล้วใส่เลขสลิป ระบบออก **ใบหัก ณ ที่จ่าย** เลขที่ `<ปี พ.ศ.>-<6 หลัก>` และส่ง Flex แจ้ง
- ทุกการเคลื่อนไหวมี Ledger (ประวัติ)

### 4.7 แอดมิน (หลังบ้าน `/admin.html`)
แท็บ: ใบสมัคร, ตรวจสลิป, แชต (ช่วยเหลือ), ชำระเงิน, แบบร่างใบสมัคร, ธง/รายงานแชต, คำขอแก้ไข/ลบโปรไฟล์, สังกัด, Vendor, สมาชิก, ไม่ใช้งาน, ถอนเงิน
- Flex เข้า LINE แอดมินทุกครั้งที่มีงาน (ใบสมัครใหม่, สลิปรอตรวจ, แชตผิดกฎ, ฯลฯ) มีปุ่มกดเปิดแท็บที่เกี่ยวข้อง
- แอดมินแก้ใบสมัครได้แม้อนุมัติแล้ว, สร้างแบบร่างแทนน้อง/นำเข้าเป็นชุด (ไฟล์ Excel/Sheet), ปรับสมาชิก, ตั้งค่าธรรมเนียมและภาษี

## 5. เส้นทางหลัก (User Journey) ที่แนะนำเป็นโครงเรื่องวิดีโอ
1. **ลูกค้าเจอ DekEn** → เปิดลิงก์ใน LINE → เห็นหมวด/น้อง (บางส่วนปิดหน้า) → ซื้อแพ็กเกจ/เติม Wallet ด้วย QR → รูปชัดขึ้น
2. **ลูกค้าแชตกับน้อง** → น้องตอบ → มีแจ้งเตือนแดง → ตกลง → **จอง** → หัก 500/700 → น้องรับงาน → ได้รับ Flex
3. **เงินไหลอย่างไร** ค่าจอง 500: 40% ผู้ชวนน้อง (recruiter), 40% เซลล์ที่พาลูกค้า (ถ้าไม่มี/หมดอายุ ตกเป็นของแพลตฟอร์ม), 20% แพลตฟอร์ม
4. **น้องสมัคร** → แอดมินอนุมัติ → ออนไลน์ทันที → รับงาน → **ถอนรายได้** → ใบหัก ณ ที่จ่าย
5. **โมเดลลิ่ง** สมัคร → จ่ายแพ็กเกจ → ชวนน้อง/สร้างแบบร่าง → โลโก้ขึ้นแถบสังกัด
6. **แอดมิน** เห็นทุกอย่างผ่าน Flex และหลังบ้าน ตรวจ/อนุมัติ/โอนเงิน

## 7. จุดขาย (Key Messages) ที่เหมาะกับการพรีเซนต์
1. **ทำงานทั้งหมดในแอป LINE** ไม่ต้องดาวน์โหลดแอปใหม่ ไม่ต้องสมัครสมาชิก
2. **ปลอดภัยและเป็นธรรม**: ระบบตัดสินเรื่องเงินและสิทธิ์ที่เซิร์ฟเวอร์ ลำดับน้องสุ่มหมุนเวียน รูปผู้ไม่มีแพ็กเกจถูกปิดหน้า
3. **ทุกฝ่ายมีรายได้**: น้อง ผู้ชวน เซลล์ สังกัด และแพลตฟอร์ม
4. **แอดมินคุมได้ง่าย**: Flex เข้า LINE พร้อมปุ่มลัด คิวตรวจ/โอนเงินในที่เดียว
5. **เป็นระบบ**: การเงินมี Ledger, ใบหัก ณ ที่จ่าย, การเข้ารหัสข้อมูลส่วนบุคคล

## 8. ข้อห้าม/ข้อควรระวังในการทำวิดีโอ
- วิดีโอนี้เป็นสื่อภายใน/นักลงทุน/ทีมงาน เนื้อหาเกี่ยวกับธุรกิจบริการผู้ใหญ่ ห้ามใช้รูปบุคคลจริง ห้ามใช้รูปโป๊หรือเปิดเผยหน้า ใช้ภาพ Mockup / ภาพจำลองที่ไม่ระบุตัวบุคคล
- ห้ามแสดงข้อมูลจริง: LINE userId, เลขบัตร, เลขบัญชี, secret/token, URL โปรเจกต์จริง, ภาพหน้าจอที่มีชื่อผู้ใช้จริง
- ห้ามอ้างผลการใช้งานจริงหรือรายได้ที่ยังไม่มี
- เรื่องภาษี (หัก 3% / ใบหัก ณ ที่จ่าย) และการริบยอดเงินเมื่อไม่ใช้งาน เป็นเรื่องที่ยังต้องให้นักบัญชี/ทนายยืนยัน อย่าพูดว่าถูกต้องตามกฎหมายแล้ว
- ภาษาในวิดีโอ: ไทยเป็นหลัก (แอปมี ไทย/EN/中文)
